# 论文速读：LANGSAMP-Language-Script-Aware-Multilingual-Pretraining

## 一句话总结
本文提出 LANGSAMP，一种在多语言预训练阶段引入可学习的语言嵌入和书写系统嵌入的方法，通过将这两种嵌入加到 Transformer 块输出后输入 MLM 头，分担 token 表示中编码语言/脚本特定信息的负担，从而获得更语言中性的表示，最终在零样本跨语言迁移任务上稳定提升性能。

## 研究问题与动机
- **核心问题**：当前主流多语言预训练模型（如 XLM-R、mBERT）不使用语言嵌入，导致 token 表示必须独自编码所有语言特异性信息，削弱了语言中性（language neutrality），进而损害零样本跨语言迁移效果。
- **早期方法遗留**：XLM 等早期模型曾在词嵌入层前添加语言嵌入以分流负担，但后来被丢弃——原因是希望统一参数集、无需语言 ID 即可作通用编码器；这一丢弃反而降低了语言中性。
- **后对齐方案局限**：现有工作多在预训练后对表示进行后对齐（post-alignment），但很少从预训练架构层面直接增强语言中性。
- **动机**：从架构设计出发，在预训练阶段引入语言/书写系统嵌入，使 Transformer 输出不必编码过多语言/脚本特定信息，从而获得更语言中性的表示，而在微调时仍可像普通 mPLM 一样无需语言 ID 输入。

## 核心贡献（创新点）
1. **提出 LANGSAMP 方法**：在 Transformer 块输出之后、MLM 头之前加入语言嵌入和书写系统嵌入，分流表示负担；与已有工作在预训练前加语言嵌入的做法（如 XLM）的本质区别在于添加位置不同，使得微调阶段 backbone 完全无需语言 ID。
2. **系统验证语言中性提升与迁移收益**：在 Glot500-c（500+语言）上对 XLM-R 继续预训练，在句子检索、文本分类、序列标注三类零样本跨语言迁移任务上全面超越基线；本质区别在于此前工作多依赖后对齐，本文从预训练架构直接优化。
3. **揭示语言嵌入的副产物价值**：通过 PCA 可视化和余弦相似度分析证明语言/书写系统嵌入捕捉了类型学特征；基于此的源语言选择案例研究显示可用嵌入相似度为跨语言迁移选择更优 donor 语言，这是以往 xlm-r 类模型不具备的额外能力。

## 方法详解
- **语言与书写系统嵌入定义**：设 $E^{\text{Lang}} \in \mathbb{R}^{L \times D}$ 为语言嵌入矩阵（$L=610$ 种语言），$E^{\text{Script}} \in \mathbb{R}^{S \times D}$ 为书写系统嵌入矩阵（$S=30$ 种书写系统），$D=768$ 为模型维度，随机初始化。
- **LANGSAMP 建模过程**：对来自语言 $l$、书写系统 $s$ 的句子 $X=[x_1,\dots,x_n]$，经 Transformer 块得到最后一层上下文嵌入 $H=[h_1,\dots,h_n]$，然后在 MLM 解码前叠加：
  $$o_i = h_i + E_l^{\text{Lang}} + E_s^{\text{Script}}$$
  MLM 损失为：
  $$\mathcal{L}_{\text{MLM}} = -\sum_{i \in \mathcal{M}} \log P_{\text{MLM}}(x_i \mid o_i)$$
  其中 $\mathcal{M}$ 为掩码位置集合。由于 $o_i$ 获得语言/书写系统提示，$h_i$ 不必编码此类信息，因而更语言中性。
- **微调阶段无额外开销**：下游任务直接使用 $H$（不含语言/书写系统嵌入），与传统 XLM-R 微调方式完全一致，不增加推理参数量，也不需输入语言 ID。
- **与早期做法的本质差异**：XLM 将语言嵌入加在词嵌入层前（输入 Transformer 之前），要求推理时传入语言 ID；LANGSAMP 将嵌入加在 Transformer 输出后，仅用于预训练辅助解码，推理时无需任何语言/书写系统标识。

## 实验与结果
- **数据与设置**：以 XLM-R 权重初始化，在 Glot500-c（500+语言、30种书写系统）上继续预训练；学习率 5e-5，AdamW，有效 batch size=1024，共约 150K 步（约 4 周，4×NVIDIA RTX6000）。
- **评估任务**：六项下游任务——句子检索 SR-B（Bible）、SR-T（Tatoeba）；文本分类 Taxi1500、SIB200；序列标注 NER（WikiANN）、POS（Universal Dependencies）。采用英语中心 zero-shot 跨语言迁移评估。
- **主要结果（Table 1，all languages）**：

  | 任务 | 基线 | LANGSAMP | 提升 |
  |------|------|----------|------|
  | SR-B | 42.9 | 45.1 | +2.2 |
  | SR-T | 69.7 | 71.1 | +1.4 |
  | Taxi1500 | 50.3 | 53.4 | +3.1 |
  | SIB200 | 75.0 | 75.9 | +0.9 |
  | NER | 62.2 | 62.6 | +0.4 |
  | POS | 71.5 | 71.6 | +0.1 |

- **分层结果**：tail（低资源）语言提升更显著，如 SR-B tail 从 36.9→39.5（+7%），head 仅 +1%；拉丁语与非拉丁语均有提升，表明书写系统嵌入的作用。
- **消融（Table 2，5%数据）**：仅加 $E^{\text{Lang}}$ 或仅加 $E^{\text{Script}}$ 均带来一致提升；两者结合取得最佳整体性能，验证两种嵌入各有贡献且互补。
- **语言中性验证（Figure 4）**：10种类型学和书写系统差异大的语言配对余弦相似度全部提升；其中 arb_Arab 与其他9语言的相似度提升最大（eng: +4.7%，rus: +4.1%）。

## 相关工作脉络
1. **XLM (Conneau & Lample, 2019)**：早期在多语言模型中使用语言嵌入，加在 token embedding 前，需语言 ID 作为输入；LANGSAMP 借鉴其思想但改变添加位置，推理时无需语言 ID。
2. **XLM-R / mBERT**：去除语言嵌入以实现统一编码器；本文认为这是语言中性下降的根源，主张在预训练阶段以轻量方式恢复该能力。
3. **后对齐方法 (Cao et al., 2020; Pan et al., 2021; Liu et al., 2024b; Xhelili et al., 2024)**：在预训练后进行跨语言表示对齐；本文方法从预训练架构层面直接优化语言中性，不依赖后处理对齐。
4. **Glot500 / Glot500-m (ImaniGooghari et al., 2023)**：大规模多语言语料与模型；本文基线与 Glot500-m 等价，在此基础上通过引入嵌入实现进一步提升。
5. **跨语言源语言选择研究 (Lin et al., 2019; Lauscher et al., 2020; Wang et al., 2023)**：利用语言相似度选择最优 donor；本文证明其语言嵌入可自然派生此类相似度，为源语言选择提供新资源。
6. **Adapter 等参数高效微调方法 (Pfeiffer et al., 2022; Balne et al., 2024)**：在微调时增加额外模块；本文强调改进完全源于预训练学到的更好表示，而非额外参数容量。

## 局限性与未来方向
- **计算预算限制**：消融实验因算力所限仅使用 5% 数据，未能在全量 Glot500-c 上验证各组件的独立贡献。
- **未探索前置插入方式**：论文明确未研究将语言/书写系统嵌入加在 Transformer 块之前的架构，认为这不符合"通用编码器无需 ID"的设计目标，但承认这是有潜力的方向。
- **语言/书写系统覆盖有限**：模型仅覆盖 Glot500-c 的 610 种语言、30 种书写系统，对于未被覆盖的低资源语言虽可生成表示，但无法利用嵌入选择最优 donor 语言。
- **语言中性与迁移性能的因果关系未确立**：作者承认两者高度相关但未必因果，引用文献表明语言中性提升并不总能转化为下游性能改善。
- **未来方向**：探索在中层 Transformer 表示中引导语言中性（结合层级目标或对比学习）；将语言/书写系统嵌入扩展至 decoder-only 和 encoder-decoder 模型以支持受控多语言生成。

## 研究启发与可借鉴点
1. **嵌入位置设计精巧**：将辅助嵌入加在 Transformer 输出而非输入前，既实现了"预训练时分担负担、推理时零开销"的目标，又保持了与主流 mPLM 完全兼容的微调接口，这一设计值得在多语言扩展场景中复用。
2. **利用可学习嵌入的副产物价值**：语言嵌入在预训练中为 MLM 服务，但其学到的类型学结构可作为下游任务（如 donor 语言选择）的免费资源，这种"一石二鸟"的思路可迁移至其他辅助嵌入设计。
3. **分层评估维度的实验设计**：按 head/tail 语言和 Latin/non-Latin 书写系统交叉分组评估，清晰揭示了方法对不同资源等级和书写系统的差异化收益，这种分组策略值得在后续多语言工作中沿用。
4. **语言中性量化指标的可复现性**：使用平行语料计算 10 种语言间配对余弦相似度并减去语言质心，简洁有效地量化了语言中性，该协议可直接复用于其他多语言模型的评估。
5. **与低资源语言场景的结合机会**：本文发现 tail 语言提升幅度显著大于 head 语言，团队可进一步探索将此方法应用于非洲/南亚等极低资源语言的持续预训练中。

## 关键术语表
- **Language neutrality（语言中性）**：不同语言的句子表示应共享统一子空间，语义等价的跨语言表达在向量空间中接近，是有效跨语言迁移的前提。
- **Crosslingual transfer（跨语言迁移）**：在源语言（通常为英语）上微调模型后，直接应用于目标语言测试而不需目标语言训练数据。
- **Zero-shot crosslingual transfer（零样本跨语言迁移）**：目标语言完全没有微调数据，仅靠源语言微调后的模型直接推理。
- **Head / Tail language（头部/尾部语言）**：相对于 XLM-R 预训练数据覆盖情况，被充分覆盖的语言为 head，覆盖不足的低资源语言为 tail。
- **MLM（Masked Language Modeling，掩码语言建模）**：BERT 类自监督预训练目标，随机遮蔽部分 token 并要求模型预测。
- **Donor language（源语言/捐赠语言）**：在跨语言迁移中作为微调数据源的语言，本文探索用语言嵌入相似度自动选择最佳 donor。

## 可复现要素
- **数据集**：Glot500-c（公开）；评估数据集包括 Bible（SR-B）、Tatoeba（SR-T）、Taxi1500、SIB200、WikiANN（NER）、Universal Dependencies（POS），均为公开数据集。
- **代码**：已开源，https://github.com/cisnlp/LangSAMP
- **模型权重**：已公开提供（论文声明"make our code and models publicly available"）
- **关键超参**：XLM-R base（D=768）；语言嵌入 $\mathbb{R}^{610 \times 768}$，书写系统嵌入 $\mathbb{R}^{30 \times 768}$；学习率 5e-5，AdamW（$\beta_1=0.9, \beta_2=0.999, \epsilon=1\text{e}{-6}$），有效 batch size=1024，梯度累积 8，per-GPU batch=32，最大 150K 步，每 5K 步保存 checkpoint，早停基于下游任务平均性能。
