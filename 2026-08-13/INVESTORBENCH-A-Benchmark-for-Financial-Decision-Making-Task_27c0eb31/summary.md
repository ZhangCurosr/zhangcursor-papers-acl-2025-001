# 论文速读：INVESTORBENCH-A-Benchmark-for-Financial-Decision-Making-Task

## 一句话总结
本文提出了 INVESTORBENCH，首个专为评估 LLM 驱动智能体在多样化金融决策任务中表现的综合基准测试，覆盖股票、加密货币和 ETF 三类资产的交易决策，并开放多源数据集与标准化评测环境。

## 研究问题与动机
1. **现有金融 LLM 智能体框架缺乏通用性**：如 FINROBOT、FINMEM、FINAGENT、CRYPTO-TRADE、FINCON 等分别聚焦单一任务或有限资产类型，难以横向比较和扩展。
2. **缺少统一、公开的评测基准**：现有金融 NLP 基准（如 FLUE、Pixiu、FinBen）侧重理解类任务，缺乏针对"序列决策"能力的系统性评测平台。
3. **私有数据壁垒阻碍可复现性**：已有框架常依赖商业金融数据，限制学术社区验证与公平对比。
4. **不同市场环境的决策难度差异未被充分研究**：股票（长期基本面为主）、加密货币（高波动、强情绪驱动）、ETF（被动配置、长期视角）对智能体的推理需求截然不同。

## 核心贡献（创新点）
1. **提出首个覆盖多资产类型的金融决策 LLM 智能体基准**：INVESTORBENCH 统一评估股票、加密货币、ETF 三类任务，弥补已有基准仅关注单一场景的空白。
2. **构建开源、多模态的金融市场环境数据集**：整合 Yahoo Finance、SEC EDGAR、CoinMarketCap、Cryptonews 等公开数据源，提供可直接复用的训练/测试轨迹。
3. **设计基于 FINMEM 的分层记忆认知架构**：引入工作记忆 + 三层长时记忆（浅/中/深），通过衰减率差异化保留不同时效性金融洞察，支持跨资产泛化。
4. **系统化评测 13 种主流 LLM 的金融决策能力**：涵盖闭源商业模型（GPT-4/o1-preview）、开源基础模型（Llama/Qwen/Yi/DeepSeek）及金融微调模型（Palmyra-Fin-70B），揭示参数规模与专有模型的关键优势。

## 方法详解
**整体架构**：INVESTORBENCH 采用"LLM-as-agent"框架，由五个核心模块组成：
- **Brain/Backbone**：作为推理核心的 LLM（本次评测 13 个）。
- **Perception**：将原始市场数据（数值、文本、新闻）转换为 LLM 可解析的结构化输入。
- **Profile**：定义智能体角色（资深投资者）与自适应性风险偏好（根据历史动量动态调整风险厌恶/追求倾向）。
- **Memory**（核心创新）：
  - **工作记忆**：执行"观察 → 总结 → 反思"循环，包含即时反思与扩展反思两种机制。
  - **分层长时记忆**：借鉴人类认知衰减规律，设置浅层（14天）、中层（90天）、深层（365天）三层向量数据库，各层以不同衰减率 $\alpha_l$ 清理旧信息，并通过检索分数 $\gamma_l^E = S_{Recency} + S_{Relevancy} + S_{Importance}$ 排序 top-K 关键事件。
- **Action**：输出"Buy/Sell/Hold"三选一动作；热身阶段（训练）使用已知情报校准策略，评估阶段（测试）严格禁止使用未来价格数据。

**POMDP 建模**：将金融决策形式化为无限 horizon 部分可观测马尔可夫决策过程，优化目标为最大化折现累计收益：
$$\max_{\pi \in \Pi} \mathbb{E}\left[\sum_{t \in \mathbb{T}} \alpha^t R_t^\pi\right]$$
其中 $R_t^\pi$ 为日度 PnL，$\Pi$ 为所有语言条件策略集合。

**评估指标**：以累积收益率（CR）和夏普比率（SR）为主指标，辅以年化波动率（AV）和最大回撤（MDD）。

## 实验与结果
**数据集与环境**：
- 股票：7 只（MSFT、JNJ、UVV、HON、TSLA、AAPL、NIO），2020-07 ~ 2021-05，含 OHLCV + SEC 年报/季报 + 新闻。
- 加密货币：BTC、ETH，2023-02 ~ 2023-11，含 OHLCV + 多源新闻。
- ETF：NIFTY 数据集，2019-07 ~ 2020-09，含新闻头条与情感标签。

**关键结果**：
- **闭源模型全面领先**：GPT-4o 在多数任务中 CR 与 SR 最高（如 MSFT CR=12.461，TSLA CR=45.946，ETH SR=0.275）。
- **参数规模正相关**：开源模型中 >67B 参数版本（Llama-3.1-70B、DeepSeek-67B、Qwen2.5-72B）显著优于小模型；小型模型（<10B）在加密货币等高频任务中表现弱于 Buy & Hold 基线。
- **金融微调模型并非更优**：Palmyra-Fin-70B 在股票与加密货币任务中反而低于基线，因其训练目标偏向长文档理解而非序列决策。
- **ETF 投资最依赖大模型推理**：闭源模型平均 CR=12.108%，开源平均仅 5.825%，因 ETF 需跨板块综合判断。

**最强结果**：GPT-4o 在 TSLA 股票交易中达到 CR=45.946%、SR=0.930；Llama-3.1-8B 在 MSFT 上 CR=22.703%、SR=0.912，展现小模型特定场景下的竞争力。

## 相关工作脉络
1. **FINMEM (Yu et al., 2024)**：本文框架的基础，专注单只股票交易；INVESTORBENCH 扩展至三类资产并开放完整数据集。
2. **FINAGENT (Zhang et al., 2024)**：基于纯相似度检索的记忆机制；本文采用分层衰减记忆，更适合多时效性金融信号。
3. **CRYPTO-TRADE (Li et al., 2024)**：仅面向加密货币零样本交易；本文统一评估三种资产，便于跨领域对比。
4. **FLUE / Pixiu / FinBen (Shah et al., 2022; Xie et al., 2023, 2024)**：均为金融 NLP 理解类基准；本文首次聚焦"序列决策 + 实时交互"场景。
5. **FINROBOT (Yang et al., 2024) / FINCON (Yu et al., 2024b)**：前者偏市场分析，后者处理极简组合（仅三只股票）；本文覆盖更广泛单资产任务并提供标准评测代码。

## 局限性与未来方向
**局限性**：
1. 当前仅限单资产决策，未涉及多资产投资组合管理（附录 D 仅展示初步尝试）。
2. 数据集受版权与公开来源限制，新闻与财务数据覆盖面有限。
3. 未引入音频（如财报电话会议录音）或图表（K线图）等多模态信号。

**未来方向**：
- 扩展至多资产组合优化与动态再平衡任务。
- 融合非文本模态（音频、图表）增强感知能力。
- 支持更多金融子领域（衍生品、固定收益、宏观对冲）。

## 研究启发与可借鉴点
1. **分层记忆机制可直接迁移**：浅/中/深三层 + 指数衰减的存储策略，适用于任何需要长短期记忆分离的时序决策任务（如游戏 AI、机器人控制）。
2. **自适应性风险偏好设计**：将"历史动量正/负"映射为风险寻求/厌恶角色，是低成本提升策略鲁棒性的有效手段。
3. **统一基准的价值**：在金融智能体领域建立像 GLUE/SuperGLUE 一样的标准评测平台，可推动领域内可复现研究与公平比较。
4. **实验协议规范化**：明确区分"热身阶段"（允许使用未来数据校准）与"评估阶段"（严格禁止），为决策类任务提供可复现的实验范式。

## 关键术语表
**INVESTORBENCH**：首个面向 LLM 智能体金融决策的多任务开源基准测试平台。
**POMDP（部分可观测马尔可夫决策过程）**：用于建模金融决策的数学框架，智能体无法直接观测完整市场状态，仅能获得部分观测信号。
**Working Memory（工作记忆）**：智能体短期处理模块，负责当前信息的观察、总结与即时反思。
**Layered Long-Term Memory（分层长时记忆）**：基于时间衰减率的三层记忆架构，实现不同时效性金融洞察的差异化存储与检索。
**CR（Cumulative Return，累积收益率）**：衡量投资周期内总收益的核心指标，计算公式为各日对数收益率之和。
**SR（Sharpe Ratio，夏普比率）**：风险调整后收益指标，等于超额收益均值除以收益波动率。
**Warm-up Phase（热身阶段）**：训练期，允许智能体利用完整历史数据建立记忆库并校准策略。
**Buy & Hold Baseline**：被动投资策略基线，全程持有标的资产不进行买卖操作，用于对比主动决策的增量价值。

## 可复现要素
- **数据集**：公开开源（Yahoo Finance、SEC EDGAR、CoinMarketCap、NIFTY 等），MIT 许可证，可通过 GitHub 获取。
- **代码**：开源，地址 https://github.com/felis33/INVESTOR-BENCH。
- **模型权重**：使用 13 个现有开源/闭源 LLM，未提出新模型权重。
- **关键超参**：温度参数 temperature=0.6；分层记忆时间窗口 Q_shallow=14天、Q_intermediate=90天、Q_deep=365天；重要性衰减系数 α_shallow=0.9、α_intermediate=0.967、α_deep=0.988。
- **部署硬件**：小模型（<10B）用 2×RTX A6000；中模型（10B-65B）用 4×RTX A6000；大模型（>65B）用 8×A100 80GB。
